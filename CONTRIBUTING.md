# Contributing to GEMINI X HERMES

Thank you for your interest in enhancing the **GEMINI X HERMES** cognitive architecture.

---

## How to Contribute

1. **Fork the Repository** to your GitHub account.
2. **Clone Locally**:
   ```bash
   git clone https://github.com/your-username/GEMINI-X-HERMES.git
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/cognitive-enhancement
   ```
4. **Follow the Hermes Completion Contract**:
   - Ensure `SKILL.md` contains valid YAML frontmatter.
   - Any new references must be located under `skills/hermes-cognition/references/` or `docs/`.
   - Test scripts locally with PowerShell and Bash.
5. **Submit a Pull Request** with a detailed explanation of changes and empirical test results.
