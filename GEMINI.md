# Gemini / Antigravity Workspace Guidelines

This repository hosts **GEMINI X HERMES**, the autonomous cognitive intelligence framework for Google Antigravity.

### Workspace Context:
- **Global Skill Directory**: `~/.gemini/config/skills/hermes-cognition`
- **Installed Skills**: `hermes-cognition` is registered globally.
- **Verification Rule**: Verify all PowerShell and Bash scripts prior to committing.
